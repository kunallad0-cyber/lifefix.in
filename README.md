
LifeFix AI 🇮🇳
Gemini-Powered Universal AI Problem Solver & Real-Time Scam Shield

LifeFix AI is an intelligent assistant designed to help users navigate everyday household issues, analyze suspicious digital communications, track regional utility/safety advisories, and manage personal life memory vaults—all tailored with localized context (such as Mumbai utilities, UPI fraud defense, and local service networks).
🌟 Key Features
• Universal AI Problem Solver: Describe any problem—from a noisy water heater and leaking pipes to unexpected utility bills—and receive step-by-step diagnostic assistance.
• Scam Shield & Fraud Defense: Real-time protection against digital arrests, fraudulent UPI/MSEDCL bill texts, and phishing links with direct integration to national cyber helplines (e.g., India's 1930 Cyber Helpline).
• Live GPS Radar & Regional Advisories: Location-aware safety and utility tracking for active local scams, power outages, seasonal climate hazards, and emergency dispatches.
• AI Memory Vault: Securely stores context like home appliance specs (e.g., HVAC models), family health profiles (allergies, primary doctors), and preferred local service providers to personalize future troubleshooting.
• Verified Local Services Directory: Instantly connects users with trusted regional professionals (plumbers, electricians, clinics) complete with ratings, distances, and standardized service pricing.
• Progressive Web App (PWA) Support: 1-click installation across Android, iOS, Windows, and Mac with zero-footprint offline readiness.
📱 Tech Stack & Architecture
• Core Engine: Powered by Gemini AI for multimodal problem-solving, intent parsing, and advisory generation.
• Frontend: Responsive web interface optimized for mobile and desktop viewports.
• Storage / Memory: Client-side & cloud-synced AI Memory Vault for contextual continuity.
• Location & Services: Geolocation-based routing for local safety radars and emergency provider mapping.
